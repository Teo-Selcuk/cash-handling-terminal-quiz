# Typing speed

Select **Typing speed** on setup. Easy starts with 30 characters / 30 seconds, Medium with 60 / 30, and Hard with 100 / 25. Hard includes mixed case, numbers, and punctuation. Choose words or random characters. Word prompts stop at the last complete word within the configured target (1–500); very small targets still produce one whole word. Random prompts use exactly the requested count. Rounds and history show the actual prompt length. Legacy phrases presets load as words.

Override typing time (3–300 seconds), rounds (1–100), and character count. Save/reset applies to the selected difficulty on this device. Optional hidden prompts display for a configurable preview (1–60 seconds) before typing begins. Preview time does not count toward typing speed. Press Enter once (or Ready to type) to start, then Enter again (or Submit) to submit. Hidden-prompt rounds retain their preview before typing starts. Paste/drop is disabled; Backspace corrections are allowed. The final submitted text is scored, not the number of keystrokes or previously corrected errors.

Matching is exact and position based: case, spaces, and punctuation count. Character accuracy is matching positions divided by the larger of target and answer length. CPM counts correctly matched characters per minute; WPM is CPM / 5. Sessions aggregate characters and elapsed typing time rather than averaging round rates. Timeout includes the partial answer and uses the configured typing limit. No automatic finish occurs when a prompt is matched; submit it to end the timer.

Reached rounds are checkpointed as Not answered using the existing local history, and replaced on submission. History / Progress includes Typing Speed, content/load/speed filters, WPM and character-accuracy charts, speed metrics, and expected/entered text. Existing attempts are preserved. CSV includes typing fields. Compare equivalent difficulty, content, timer, character count, and visibility settings.
