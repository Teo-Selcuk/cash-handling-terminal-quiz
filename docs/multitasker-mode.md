# Multitasker / OVERLOAD

Select Multitasker in browser setup. The PowerShell cash trainer is unchanged. Select 1–9 starting tasks, maximum tasks, mode, deadline, speed, initial difficulty, points per increase, auto-add, optional sound and warning animation, and duration (zero means untimed). Included tasks and their unlock thresholds are editable. Excluding every task displays a setup error.

Standard permits no mistakes. Practice permits unlimited mistakes. Endurance and Custom end after the configured mistake allowance is exceeded. Default unlock points are 20 for arrows, 40 for wires, 60 for patterns, 80 for cards, and 100 for moles. Initial math, shapes, ball, and color tasks are unlocked. Practice and Custom initially unlock selected tasks; uncheck that option to use the thresholds. Explicitly selecting only a locked task starts that task so individual practice remains possible.

Every task retains its own trial, deadline, and study/wait phase. A response resets only that task. Higher levels shorten deadlines, increase math and memory complexity, and optionally add panels. Pattern and card study time precedes the response deadline. Mole visibility starts after a brief spawn wait. Falling balls are judged automatically when they land. Cards award one point for any matching pair, then generate a new board.

Use the visible buttons or keyboard. Enter submits math, arrows answer the opposite-arrow panel or move a focused catcher, number keys select shapes/cards/patterns/moles, and Alt+1–9 focuses a panel. Pause freezes every task clock and the survival clock. Hiding the browser tab pauses automatically; Resume continues. End run or History saves the completed run. Periodic checkpoints preserve interrupted runs as Not answered, excluded from completed-run recommendations. A page reload preserves evidence, rather than resuming an unfinished arena.

History saves every action with expected/submitted inputs, trial configuration, response time, deadline, difficulty, active task combination, urgency overlap, expiration, rushed responses, task switches, and run settings. Automatic catches and expirations save immediately. Run accuracy counts actions; the shared outcome metric counts completed runs. A manually stopped practice run can therefore have a completed outcome with action errors, which remain visible in the dedicated metrics and error analysis.

Task strengths and weaknesses require at least three completed runs and 15 actions for that task. Recommendations select one fixed-count Practice plan using the weakest supported task plus a stronger task, or the task count where accuracy drops by at least 15 percentage points. The plan uses generous timers and disables automatic task additions. Sample recommendations cannot alter the real active challenge.

Sample Data is generated deterministically from its stored seed and stays in session storage. It spans all four modes, 1–9 task counts, difficulty and response-time profiles, trend changes, task-specific errors, and pressure combinations. Real Data remains in the existing local history store. Eleven charts and bounded tables share existing zoom, appearance, table, Minimize, Expand, and evidence controls.

Validation: unit tests cover trial scoring, independent clocks, mistake budgets, unlocks, scaling, raw inputs, sample isolation, filtering, analytics, and recommendations. Browser tests exercise all nine task controls, 1–9 concurrent panels, pause, modes, persistence, 320/768/1440px layouts, Real/Sample analytics, and raw activity inspection. The full regression suite also exercises existing games and history controls.
